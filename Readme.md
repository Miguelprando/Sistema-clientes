Sistema de Registro de Clientes

Projeto desenvolvido em Python com o objetivo de praticar lógica de programação, funções, listas e manipulação de arquivos JSON.

Sobre o projeto

O Sistema de Registro de Clientes é uma aplicação de terminal que permite cadastrar, listar, pesquisar e excluir clientes.

Os dados são armazenados localmente em um arquivo JSON, permitindo que os registros continuem disponíveis após fechar e abrir o programa.

Funcionalidades

Cadastro de clientes.

Listagem de clientes cadastrados.

Pesquisa de clientes.

Exclusão de clientes.

Salvamento automático dos dados em JSON.

Carregamento dos dados ao iniciar o programa.

Validação básica do nome no cadastro.

Tecnologias utilizadas

Python

JSON

Como executar

Instale o Python.

Baixe ou clone este repositório.

Abra a pasta do projeto no VS Code.

Execute o arquivo main.py pelo terminal:

python main.py

O arquivo clientes.json será criado automaticamente quando um cliente for cadastrado.
